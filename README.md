# 💡 Project Idea Generator

**AI-Powered Academic Project Suggestions**

Author: Pranay M

## Overview

Suggests feasible project ideas based on course objectives, with detailed plans and feasibility assessments.

## Features

- Generate project ideas
- Expand ideas into detailed plans
- Assess feasibility
- Create project timelines
- Suggest resources

## Installation

```bash
ollama pull llama3.2
pip install -r requirements.txt
python main.py
```
